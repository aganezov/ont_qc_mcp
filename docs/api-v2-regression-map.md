## Obsolete API-only expectations

The cutover removes exact legacy names, legacy descriptions/resources, compatibility-only aliases, the old composite alignment summary, and boolean include flags that only shaped old payloads. The underlying parser, numerical, path-validation, cleanup, cache, cancellation, and wire-before-worker regressions remain required through their v2 targets. Composite alignment-summary calculation is replaced by explicit `alignment_qc` and `coverage_qc` calls; removing its entry point does not authorize removing the component regressions.

The zero-retained-read nanoq parser bug in #104 is fixed by V2-03 with a pinned native-output regression. Unknown-resource behavior in #101 is separate and must not be inferred from v2 catalog or error-schema tests.
